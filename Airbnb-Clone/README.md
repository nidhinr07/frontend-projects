# Airbnb Clone

This is an Airbnb clone project that I built using HTML, CSS and JavaScript.

I created this project to practice frontend development by recreating a property booking website and working with search layouts, categories, property cards, responsive grids, and basic JavaScript interactions.

## Features

* Airbnb-style header
* Navigation menu
* Search section
* Destination and date fields
* Property categories
* Property cards
* Property ratings
* Property prices
* Guest favorite labels
* Like property button
* Category selection
* Responsive design
* Footer section

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Responsive Design

## What I Practiced

* HTML page structure
* CSS Flexbox
* CSS Grid
* Responsive layouts
* Search bar design
* Property card design
* Navigation layouts
* Image positioning
* Button styling
* JavaScript DOM manipulation
* Click events
* Updating button states
* Media queries

## JavaScript Features

The JavaScript in this project is used for:

* Liking and unliking properties
* Changing property category selection
* Handling search button interactions
* Updating button styles dynamically

## Purpose

The main purpose of this project was to practice HTML, CSS and JavaScript by recreating the basic interface of Airbnb.

This is a frontend practice project and is not connected to the actual Airbnb platform.
