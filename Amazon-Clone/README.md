# Amazon Clone

This is an Amazon clone project that I built using HTML, CSS and JavaScript.

I created this project to practice frontend development by recreating an e-commerce website layout and adding some basic JavaScript functionality.

## Features

* Amazon-style header
* Search bar
* Navigation menu
* Location section
* Shopping cart
* Hero banner
* Product categories
* Product cards
* Product ratings and prices
* Add to Cart functionality
* Product search
* Smooth scrolling
* Responsive design
* Footer sections

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Responsive Design

## What I Practiced

* HTML page structure
* CSS Flexbox
* CSS Grid
* Responsive design
* Navigation layouts
* Product card design
* Search functionality
* JavaScript DOM manipulation
* Button events
* Updating page content with JavaScript
* Smooth scrolling
* Media queries

## JavaScript Features

The JavaScript in this project is used for:

* Adding products to the cart
* Updating the cart count
* Searching products
* Displaying a message when no product is found
* Scrolling to the product section
* Scrolling back to the top of the page

## Purpose

The main purpose of this project was to practice HTML, CSS and JavaScript by recreating the basic interface of an e-commerce website.

This is a frontend practice project and is not connected to the actual Amazon platform.
