# Apple Clone

This is an Apple-style homepage clone built using HTML, CSS, and JavaScript.

I created this project to practice frontend development by recreating a clean product-focused website with navigation, product sections, responsive layouts, and basic JavaScript interactions.

## Features

* Apple-style navigation bar
* Hero section
* iPhone product section
* MacBook product card
* iPad product card
* Apple Watch product card
* AirPods section
* Footer navigation
* Hover effects
* Responsive design
* JavaScript button interactions

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Flexbox
* CSS Grid
* Responsive Design

## What I Practiced

* HTML page structure
* CSS Flexbox
* CSS Grid
* Responsive layouts
* Navigation design
* Product card layouts
* Buttons and hover effects
* JavaScript event handling
* DOM manipulation
* Media queries

## JavaScript Features

The JavaScript is used to add basic interactions to the page.

* iPhone Learn More button
* AirPods Learn More button
* Button click events
* Alert messages

## Project Structure

```text
Apple-Clone/

```

## Purpose

The purpose of this project was to practice HTML, CSS, and JavaScript by recreating a clean Apple-style product website interface.

This is a frontend practice project and is not connected to the actual Apple website.
