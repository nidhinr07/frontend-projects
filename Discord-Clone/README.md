# Discord Clone

This is a Discord-style chat interface clone built using HTML, CSS, and JavaScript.

I created this project to practice frontend development by recreating a chat application layout with server navigation, channels, messages, online members, and basic JavaScript interactions.

## Features

* Server sidebar
* Text channels
* Voice channels
* Chat interface
* Online members list
* User profile section
* Message input
* Send message functionality
* Channel selection
* Hover effects
* Responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Flexbox
* CSS Grid
* DOM Manipulation
* JavaScript Events
* Responsive Design

## What I Practiced

* Creating multi-column layouts
* CSS Flexbox
* Responsive design
* Sidebar navigation
* Chat message layouts
* User interface styling
* Form handling
* DOM manipulation
* JavaScript event listeners
* Dynamic content creation
* Media queries

## JavaScript Features

The JavaScript is used to add basic interactions to the chat interface.

* Send new messages
* Add messages dynamically
* Select different channels
* Update the active channel
* Update the channel name
* Automatically scroll to the latest message

## Project Structure

```text
Discord-Clone/
```

## Purpose

The purpose of this project was to practice HTML, CSS, and JavaScript by building a Discord-style communication interface.

This is a frontend practice project and is not connected to the actual Discord platform.
