# Dribbble Clone

A responsive Dribbble-inspired website built using HTML, CSS, and JavaScript.

This project was created to practice frontend development by recreating a modern design platform interface with responsive layouts, project cards, category filtering, search functionality, and basic JavaScript interactions.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Responsive Design

## Features

* Dribbble-inspired navigation bar
* Responsive design
* Hero section with search bar
* Design category filters
* Project/design cards
* Search projects by title, designer, or category
* Like and unlike projects
* Save and unsave projects
* Responsive layout for desktop, tablet, and mobile
* Interactive JavaScript functionality

## Project Structure

```text
dribbble-clone/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation or dependencies are required.

## Purpose

This project was built for frontend practice and to improve skills in:

* HTML page structure
* CSS layouts and responsive design
* CSS styling and hover effects
* JavaScript DOM manipulation
* Event handling
* Search and filtering functionality
* Building interactive user interfaces
