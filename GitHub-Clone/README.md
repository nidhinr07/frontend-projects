# GitHub Clone

This is a GitHub profile page clone that I built using HTML, CSS and JavaScript.

I created this project to practice frontend development by recreating a developer platform interface and working with profiles, repositories, navigation, search, and basic JavaScript interactions.

## Features

* GitHub-style header
* Search bar
* Profile section
* Profile navigation
* Popular repositories
* Repository information
* Contribution activity section
* Contribution graph
* Edit profile button
* Repository search
* Responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Responsive Design

## What I Practiced

* HTML page structure
* CSS Flexbox
* CSS Grid
* Profile layouts
* Repository card design
* Navigation layouts
* Responsive design
* JavaScript DOM manipulation
* Search functionality
* Dynamic content creation
* Button events
* Media queries

## JavaScript Features

The JavaScript in this project is used for:

* Searching repositories
* Filtering repository cards
* Creating the contribution graph
* Adding random contribution levels
* Handling the edit profile button

## Purpose

The main purpose of this project was to practice HTML, CSS and JavaScript by recreating the basic interface of a GitHub profile page.

This is a frontend practice project and is not connected to the actual GitHub platform.
