# Google Clone

This is a Google homepage clone that I built using HTML, CSS and JavaScript.

I created this project to practice frontend development by recreating a simple search engine homepage and working with layouts, responsive design, and basic JavaScript interactions.

## Features

* Google-style homepage
* Navigation links
* Google-style search bar
* Search buttons
* Language links
* Footer section
* Search input interaction
* Enter key search
* Responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Responsive Design

## What I Practiced

* HTML page structure
* CSS Flexbox
* CSS positioning
* Responsive design
* Search bar design
* Button styling
* JavaScript DOM manipulation
* Event handling
* Keyboard events
* Functions
* Media queries

## JavaScript Features

The JavaScript in this project is used for:

* Handling the Google Search button
* Handling the I'm Feeling Lucky button
* Checking the search input
* Searching when the Enter key is pressed
* Displaying search messages

## Purpose

The main purpose of this project was to practice HTML, CSS and JavaScript by recreating the basic interface of the Google homepage.

This is a frontend practice project and is not connected to the actual Google platform.
