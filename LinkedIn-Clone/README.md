# LinkedIn Clone

This is a LinkedIn clone project that I built using HTML, CSS and JavaScript.

I created this project to practice frontend development by recreating a professional social media platform and working with layouts, posts, sidebars, navigation, and basic JavaScript interactions.

## Features

* LinkedIn-style header
* Search bar
* Navigation menu
* Profile sidebar
* Create post section
* Social media feed
* Like button
* Comment and share buttons
* LinkedIn News section
* People you may know section
* Connect button
* Post search
* Responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Responsive Design

## What I Practiced

* HTML page structure
* CSS Flexbox
* CSS Grid
* Navigation layouts
* Sidebar layouts
* Social media post design
* Responsive design
* JavaScript DOM manipulation
* Event handling
* Dynamic content creation
* Search functionality
* Button interactions
* Media queries

## JavaScript Features

The JavaScript in this project is used for:

* Creating new posts
* Like and unlike posts
* Searching posts
* Connecting with suggested users
* Updating button states
* Dynamically adding content to the page

## Purpose

The main purpose of this project was to practice HTML, CSS and JavaScript by recreating the basic interface of LinkedIn.

This is a frontend practice project and is not connected to the actual LinkedIn platform.
