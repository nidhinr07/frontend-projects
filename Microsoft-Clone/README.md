# Microsoft Clone

This is a Microsoft homepage clone built using HTML, CSS, and JavaScript.

I created this project to practice frontend development by recreating a Microsoft-style homepage with navigation, product cards, responsive layouts, and basic JavaScript interactions.

## Features

* Microsoft-style navigation bar
* Microsoft logo
* Hero section
* Microsoft 365 section
* Product cards
* Call-to-action banner
* Footer navigation
* Hover effects
* Responsive design
* Basic JavaScript interactions

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Flexbox
* CSS Grid
* Responsive Design

## What I Practiced

* HTML semantic structure
* CSS Flexbox
* CSS Grid
* Responsive layouts
* Navigation design
* Card layouts
* Hover effects
* Buttons
* JavaScript event handling
* DOM manipulation
* Media queries

## JavaScript Features

The JavaScript is used to add basic interactions to the page.

* Learn More button interaction
* Explore Now button interaction
* Button click events
* Alert messages

## Project Structure


## Purpose

The purpose of this project was to practice HTML, CSS, and JavaScript by recreating a Microsoft-style website interface.

This is a frontend practice project and is not connected to the actual Microsoft website.
