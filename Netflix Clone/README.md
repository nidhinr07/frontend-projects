# Netflix Clone

This is a Netflix clone project that I built using HTML and CSS.

I created this project to practice frontend development and improve my understanding of website layouts, movie cards, navigation bars, banners, and responsive design.

## Features

* Netflix-style header
* Navigation menu
* Hero banner section
* Movie and TV show cards
* Popular movies section
* Trending section
* Continue Watching section
* Progress bars
* Responsive design
* Hover effects
* Social media icons

## Technologies Used

* HTML5
* CSS3
* Font Awesome
* Responsive Design

## What I Practiced

* HTML page structure
* CSS Flexbox
* CSS Grid concepts
* Fixed positioning
* Hero sections
* Card layouts
* Image styling
* Hover effects
* Responsive design
* Media queries
* Spacing and alignment

## Purpose

The main purpose of this project was to practice HTML and CSS by recreating the basic interface of Netflix.

This is a frontend practice project and is not connected to the actual Netflix platform.
