Pinterest Clone

This is a Pinterest-style website that I built using HTML, CSS, and JavaScript.

I created this project to practice frontend development by recreating a Pinterest-style layout with image cards, search, categories, and basic interactions.

Features

- Pinterest-style navigation bar
- Search pins
- Category filtering
- Image card layout
- Save button interaction
- Responsive design
- Mobile-friendly layout
- Hover effects

Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Design

What I Practiced

- HTML page structure
- CSS Flexbox
- CSS Columns
- Responsive design
- Card layouts
- Image styling
- JavaScript DOM manipulation
- JavaScript events
- Search and filtering
- Button interactions

Purpose

The purpose of this project was to improve my frontend development skills by recreating a Pinterest-style interface and adding basic JavaScript functionality.

This is a frontend practice project and is not connected to the actual Pinterest platform.
