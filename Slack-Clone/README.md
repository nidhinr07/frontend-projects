# Slack Clone

This is a Slack-style team communication interface built using HTML, CSS, and JavaScript.

I created this project to practice frontend development by recreating a modern workspace interface with channels, direct messages, team members, and a chat system.

## Features

* Workspace sidebar
* Channel navigation
* Direct messages section
* Chat interface
* Team members sidebar
* Online and offline status
* Message input
* Send message functionality
* Dynamic messages
* Channel selection
* Dynamic channel title
* Responsive layout
* Hover effects

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Flexbox
* CSS Grid
* DOM Manipulation
* JavaScript Events
* Responsive Design

## What I Practiced

* Creating multi-column layouts
* Building sidebar navigation
* Designing chat interfaces
* CSS Flexbox
* Responsive design
* Form handling
* DOM manipulation
* Event listeners
* Dynamic content creation
* Working with JavaScript events
* Creating reusable UI elements

## JavaScript Features

The JavaScript is used to add basic interactions to the interface.

* Send new messages
* Add messages dynamically
* Select different channels
* Change the active channel
* Update the channel title
* Update the message placeholder
* Automatically scroll to the latest message

## Purpose

The purpose of this project was to practice HTML, CSS, and JavaScript by building a Slack-style team communication interface.

This is a frontend practice project and is not connected to the actual Slack platform.
