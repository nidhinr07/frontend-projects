# Trello Clone

This is a Trello-style project management board that I built using HTML, CSS, and JavaScript.

I created this project to practice frontend development by recreating a task management interface with lists, cards, search, and basic JavaScript interactions.

## Features

* Trello-style board layout
* To Do, In Progress, and Done lists
* Add new cards
* Add new lists
* Search cards
* Task cards with labels
* Responsive layout
* Horizontal board scrolling
* Interactive buttons

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Responsive Design

## What I Practiced

* HTML page structure
* CSS Flexbox
* Responsive layouts
* Card and list components
* CSS positioning
* JavaScript DOM manipulation
* JavaScript events
* Dynamic element creation
* Search and filtering
* Handling user input

## Purpose

The purpose of this project was to improve my frontend development skills by recreating a Trello-style project management interface and adding basic JavaScript functionality.

This is a frontend practice project and is not connected to the actual Trello platform.
