# X (Twitter) Clone

This is an X (Twitter) clone project that I built using HTML, CSS and JavaScript.

I created this project to practice frontend development by recreating a social media interface and working with posts, navigation, sidebars, buttons, and basic JavaScript interactions.

## Features

* X-style sidebar navigation
* Home page layout
* For You and Following tabs
* Create post section
* Dynamic post creation
* Like button
* Follow buttons
* Trending section
* Who to follow section
* Search bar
* Responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Responsive Design

## What I Practiced

* HTML page structure
* CSS Flexbox
* CSS Grid
* Social media layouts
* Fixed navigation
* Responsive design
* Post card design
* JavaScript DOM manipulation
* Dynamic content creation
* Button events
* Updating page content
* Media queries

## JavaScript Features

The JavaScript in this project is used for:

* Creating new posts
* Adding like and unlike functionality
* Updating like counts
* Following and unfollowing users
* Updating button states
* Handling user interactions

## Purpose

The main purpose of this project was to practice HTML, CSS and JavaScript by recreating the basic interface of X (Twitter).

This is a frontend practice project and is not connected to the actual X platform.
